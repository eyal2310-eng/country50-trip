# התקנה

הסקיל בנוי כתיקייה עצמאית. יש שתי דרכים להתקין אותו — בחר לפי מה שאתה צריך.

## אפשרות א' — בכל שיחה, בכל פרויקט (מומלץ)

העתק את התיקייה לתיקיית הסקילים האישית שלך:

**macOS / Linux**
```bash
mkdir -p ~/.claude/skills
cp -R legal-he ~/.claude/skills/
```

**Windows (PowerShell)**
```powershell
New-Item -ItemType Directory -Force "$HOME\.claude\skills"
Copy-Item -Recurse legal-he "$HOME\.claude\skills\"
```

הפעל מחדש את Claude Code. מכאן והלאה הסקיל ייטען אוטומטית בכל פעם שתבקש מסמך
משפטי בעברית — בלי שתצטרך לבקש.

## אפשרות ב' — בפרויקט אחד בלבד

השאר את התיקייה תחת `.claude/skills/legal-he/` בתוך הריפוזיטורי. הסקיל יעבוד רק
כשתעבוד בפרויקט הזה. מתאים אם תרצה לנהל את המסמכים של המשרד בריפו ייעודי.

## לוודא שהסקיל נכנס תמיד, לפני כל מסמך

התקנת הסקיל לבדה גורמת לו להיטען כשהבקשה מזוהה כמשפטית. כדי שזה יקרה **בכל**
תוצר בעברית, בלי יוצא מן הכלל, הוסף את הכלל גם לקובץ ההנחיות האישי שלך:

```bash
cat >> ~/.claude/CLAUDE.md <<'RULE'

## עברית — כלל חוסם
לפני יצירה או עריכה של כל תוצר בעברית — מסמך, מכתב, מייל, ארטיפקט או טבלה —
יש לטעון תחילה את הסקיל legal-he ולפעול לפיו, לפני כל סקיל אחר שמייצר תוצר.
docx / pdf / xlsx / pptx / artifact-design קובעים כיצד להפיק את הקובץ;
legal-he קובע מה ייכתב בו ולאיזה כיוון — ולכן הוא נטען לפניהם.
אין להפיק מסמך בלי להריץ את check_hebrew.py ולדווח על התוצאה.
RULE
```

בשני המקומות יחד — הסקיל המותקן ו-CLAUDE.md — הכלל מתקיים גם כשהבקשה מנוסחת
בלי המילה "משפטי", וגם כשסקיל אחר מוביל את המשימה.

## שני צעדים אחרי ההתקנה

1. **מלא את `references/office-profile.md`.** זה החלק היחיד שדורש עבודה ידנית,
   והוא זה שמבדיל בין מסמך גנרי למסמך של המשרד שלך. הנח את הלוגו ב-`assets/logo.png`.
2. **התקן את התלות להפקת Word:**
   ```bash
   pip install python-docx
   ```

## בדיקה שהכול עובד

בקש בצ'אט: *"תכין מכתב התראה קצר ללקוח לדוגמה, כקובץ Word"*.
אם הקובץ נפתח כשהטקסט מימין לשמאל, המספרים במקום והטבלה בסדר הנכון — הסקיל פעיל.

## מבנה התיקייה

```
legal-he/
├── SKILL.md                      ההנחיות שנטענות אוטומטית
├── INSTALL.md                    הקובץ הזה
├── references/
│   ├── rtl.md                    הגדרות RTL מדויקות לכל פורמט
│   ├── style.md                  ניסוח, מינוח, מספור, תאריכים
│   ├── structure.md              מבנה כל סוג מסמך
│   └── office-profile.md         ← למילוי
├── templates/
│   ├── letter.md                 מכתב / מכתב התראה
│   ├── legal-opinion.md          חוות דעת
│   └── meeting-note.md           תרשומת פגישה
└── assets/
    ├── rtl_docx.py               הפקת Word עם RTL מלא + הגנת bidi אוטומטית
    └── check_hebrew.py           בודק אוטומטי — חובה להריץ לפני כל מסירה
```

## הרחבה

הסקיל בנוי להתרחב. כדי להוסיף סוג מסמך:
1. הוסף שלד ל-`templates/`
2. הוסף את המבנה שלו ל-`references/structure.md`
3. הוסף נוסחי קבע של המשרד ל-`references/office-profile.md`

ככל שתזין לתוכו נוסחים אמיתיים של המשרד, כך המסמכים ייצאו קרובים יותר לגמורים.
